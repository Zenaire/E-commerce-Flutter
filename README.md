# E-commerce

Project Flutter sederhana untuk latihan UI e-commerce.

Ini sekadar template/latihan, jadi bisa langsung di-clone dan dipakai sebagai awal mulai project. Kalau mau, tinggal sesuaikan isi datanya sendiri sesuai kebutuhan.

## Fitur

- Tampilan home produk
- Kategori produk
- Keranjang belanja
- Halaman akun
- Login dan register sederhana
- Chat sederhana

## Teknologi

- Flutter
- Dart

## Cara pakai

```bash
git clone <repo-url>
cd E-commerseApp_Dart
flutter pub get
flutter run
```

## Catatan

Ini bukan app yang fully complete atau siap produksi. Fokusnya lebih ke belajar struktur Flutter, layout, dan UI. Sisanya bisa diubah atau dikembangkan sendiri sesuai kebutuhan.
